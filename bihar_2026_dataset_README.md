# Bihar 2026 discharge data

## Files

- `bihar_wrd_2026_discharge_jul13_sep23.csv`: dated intraday discharge observations.
- `analyze_bihar_2026_discharge.R`: R code to inspect and plot the observations.
- `river_discharge.csv`: daily peak and mean discharge feature for the four monitored sites located in Bihar.

## Source and collection

Source: Water Resources Department, Government of Bihar, [River Discharge Dashboard](https://wrd.bihar.gov.in/rivers/2026/displayDischarge.php). The dashboard has a date selector. The CSV was assembled by retrieving the dated dashboard page for each date from 1 June through 23 September 2026. The earliest date with discharge observations in the dashboard was 13 July 2026.

The file contains 2,131 intraday records from six dashboard sites: Kosi (Barahkshetra site), Kosi (Birpur Barrage D/S), Gandak (Valmikinagar Barrage D/S), Sone (Indrapuri Barrage D/S), Falgu (Uderasthan Barrage D/S), and North Koel (Mohammadganj Barrage D/S). The unit is cusecs. The five sites other than Falgu have observations on all 73 dates from 13 July through 23 September; Falgu has observations on 68 dates.

## Bihar district discharge feature

`river_discharge.csv` is generated by the R pipeline from the daily site summaries. It contains 287 district-date rows for the four selected dashboard sites mapped to Bihar locations: Sone / Indrapuri Barrage (Rohtas), Gandak / Valmikinagar Barrage (Pashchim Champaran), Kosi / Birpur Barrage D/S (Supaul), and Falgu / Uderasthan Barrage D/S (Jehanabad). Each row includes the daily peak (`river_discharge_cusecs`), daily mean, and peak converted to m³/s. Barahkshetra (Nepal) and Mohammadganj (Jharkhand) are excluded from this Bihar-district feature.

Use `district` as a potential key when joining this feature to district-level population data, and retain `date` for date-specific analysis. A population file is not included here, so this pipeline currently exports discharge as a separate feature table; it does not yet merge population and discharge.

## Important scope limits

This is a selected-site 2026 event dataset, not a complete record for all Bihar rivers or all flood-monitoring stations. It contains intraday dashboard observations, not household-level impacts, deaths, inundation maps, or rainfall. The R script summarizes and plots the available discharge observations; it does not claim to predict floods or casualties. For flood-threshold analysis, combine it only with verified, station-matched official warning and danger levels.

The earlier NWIC Bihar discharge file ends in May 2025. It can provide historical context where stations and units match, but it contains no 2026 observations.
